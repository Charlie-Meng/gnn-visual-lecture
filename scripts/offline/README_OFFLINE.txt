GNN Visual Lecture - Offline Package
=====================================

Do not open index.html directly. Modern browsers restrict JavaScript modules,
embedded applications, and service workers on file:// URLs.

Windows
-------
Double-click start-windows.bat. Python 3 is required.

macOS / Linux
-------------
Open a terminal in this folder and run:

  ./start-local.sh

The presentation opens at http://localhost:4180/.
Press Ctrl+C in the terminal window to stop the local server.
